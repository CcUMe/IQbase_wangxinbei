当前模型是一条串行主干：一次有效区间归一化与时频前端 → BiLSTM → 三阶段编码 → token投影 → 原Transformer核心 → 跨层读出 → 三任务头。已去掉此前并行结构中的第二套时域前端、局部谱编码器及原始时频融合。

原Transformer的blocks、norm、position_projection参数结构和key保留；其输入由共享前端及阶段编码提供，分布已经变化，不能再声称原完整主干特征值保持不变。当前从零监督，旧完整pt不能直接resume；没有加载旧pt或证明旧权重迁移收益。

## 1. 整体尺寸

以下省略batch维B，长度L=1024；512点的时间长度全部减半。

| 组件 | 输入 | 输出 | 对接说明 |
|---|---|---|---|
| 有效区间与RMS | 1024×2＋长度 | 1024×2、原始RMS | padding先清零，只按有效长度归一化 |
| 时域复数卷积 | 2×1024 | 64×1024 | 32复通道=64实通道，核5、stride1 |
| 时域投影 | 1024×64 | 1024×64 | 转回时间在前的格式，Linear/LN/GELU |
| I-STFT嵌入 | 1024×64 | 1024×32 | 31点Blackman，DFT128，32个bin实虚拼接 |
| 复I/Q功率谱嵌入 | 1024×63 | 1024×32 | 63点Hann，完整复信号DFT谱形，log1p |
| 共享频谱混合 | 两份1024×32 | 1024×64 | 两种局部频域视图合并为一条频域表示 |
| 全局谱描述 | 1024个功率bin | 64维 | 计算一次，归一化/投影后并入同一频域表示 |
| 唯一时频融合 | 时域64＋频域64 | 1024×64 | 拼接128，门控联合增量，保留时域残差 |
| 两层BiLSTM | 1024×64 | 1024×64 | 每方向hidden32，投影＋残差＋LN |
| 阶段1：1块 | 1024×64 | 1024×64 | 局部卷积＋加性全局注意力＋SwiGLU |
| 阶段间下采样1 | 1024×64 | 512×128 | Conv1d核4、stride2、pad1 |
| 阶段2：2块 | 512×128 | 512×128 | 同类块，宽度128 |
| 阶段间下采样2 | 512×128 | 256×192 | Conv1d核4、stride2、pad1 |
| 阶段3：2块 | 256×192 | 256×192 | 同类块，宽度192 |
| Transformer输入投影 | 256×192 | 64×384 | Conv1d核4/stride4，再LayerNorm |
| Transformer核心 | 64×384 | 64×384 | 原8层Block，6头、每头64，QK归一化、RoPE |

两种局部谱与全局谱各有一个明确的变换，它们统一进入一次时频融合；没有两条各自从原始信号走到独立分类器的完整网络。跨层读出融合处理的是同一主干不同深度的特征。

## 2. 频谱与时间索引

I-STFT的i_nfft=128设定频率网格，观察窗口仍为31个原始点。前32个bin的实部和虚部共64维，经投影得到32维。复I/Q局部谱则提供63个频率bin的功率表示；它丢弃局部频谱相位，时域流与I-STFT实虚部仍提供相位相关输入。没有把任何频率bin解释为已知Hz，真实采样率仍未知。

合并时检查到旧31/64点窗设置的中心约定可能不一致。当前serial模式要求centered_windows=true，采用奇数、对称的31/63点窗，hop1；冲激专项测试验证两种局部频谱的能量峰均位于同一个原样点，对称偏移也一致。历史模式继续保留原窗口定义，避免静默改变旧checkpoint语义。

token几何位置逐层为：

- 阶段1：j；
- 阶段2：0.5+2j；
- 阶段3：1.5+4j；
- 末端4倍投影：7.5+16j。

因此末端投影与原P16 Transformer中心吻合。审计逐点比较投影窗口内上层token中心的均值与Transformer中心，最大误差为0。位置投影/跨层读出统一使用reference_length=1024；不兼容的累计步长、参考长度和窗口设置会在配置解析时报错。

这些是索引与几何中心的一致性，不意味着每个token只含对应小窗口的信息；BiLSTM和全局注意力已经引入远程上下文。

## 3. 编码块内部

三个阶段都采用同一类块，只调整宽度和块数。先LN、逐通道5点卷积，再用D→2D→D的点式映射混合通道；其后是高效加性注意力，最后是SwiGLU前馈。三段均有独立残差与可学习缩放，初值0.1。

高效加性注意力先产生Q/K，沿时间聚合一个全局向量，再与各位置特征交互；时间聚合系数采用带mask的L2归一化，并非标准softmax注意力矩阵。高分辨率部分不构造1024×1024自注意力。默认SwiGLU内部隐藏宽度按等量级参数折算并对齐8，三个阶段分别为168、336、512。

后半段Transformer仍是原Block：LN→带RoPE的多头自注意力→残差，LN→GELU前馈→残差，8层、D384、6头、每头64、FFN隐藏1536。这些Block不重新提取原始I/Q或STFT，它们只接收已经融合的token。

## 4. 跨层读出与任务头

读出顺序为Transformer末层、阶段3、阶段1，原维度分别384/192/64。每层投影到192维，共1344个有效token；512点输入则为32+128+512=672个。位置/长度投影和层级embedding区分相同索引在不同层的实际含义。

每层先以有效token均值初始化摘要，摘要读取其他两层token并更新；原token保留给统计池化和参数查询。此步骤属于跨层语义读出，不重复原始时频提取。

| 任务头 | 实际读取 | 输出 |
|---|---|---|
| 调制 | 每层原token的注意力均值/标准差＋融合摘要；3D投影256，三份拼接768→256 | B×23 logits |
| 协议 | 三层摘要各投影256，拼接768→128 | B×8 logits |
| 参数 | 七个192维查询读取1344×192共享memory；每字段局部192＋全局192 | B×7标准化预测 |

参数头的全局输入为三层摘要384+192+64、log RMS与有效长度，共642维，投影192。每字段独立384→128→1。当前data_full中符号率/带宽/频移/脉冲数分别有6/21/13/5个训练侧候选值，采用网格期望＋0.1×tanh残差；脉宽/PRI/时延为连续回归。推理七字段全部输出并逆标准化，不读取真实标签或有效性mask。

输入RMS归一化与输出标签标准化是两件事：前者稳定输入幅度并保留原始幅度侧信息；后者按训练集每字段中心/尺度处理回归单位。

## 5. padding与数值精度

BiLSTM按真实512/1024长度分组，反向递归不会经过padding。卷积阶段、加性注意力沿时间的归一化、Transformer key、池化与参数查询全部使用各自尺度mask。逐token LayerNorm不把padding纳入跨样本/跨时间统计。

原始归一化及固定DFT在FP32；默认BiLSTM也用FP32。阶段/Transformer投影跟随BF16自动混合精度，三个任务读出、方差、参数解码及损失使用FP32。组件间有显式dtype转换，未发现类型不匹配或非有限梯度。CPU审计不替代目标CUDA/国产设备实测。

完整默认模型的native512与pad1024输出最大差约1.2e-7以内；任意有限padding扰动误差为0。零输入、极低幅度与普通幅度的BF16专项前后向也通过。

## 6. 梯度、权重与竞赛边界

完整尺寸联合输出梯度审计没有未连接计算图的共享参数；缩小尺寸的逐任务监督检查也确认调制、协议、参数梯度均能通过Transformer、投影、所有阶段、BiLSTM及共享时频前端。缺少有效标签的字段头继续由现有AdamW活动头保护处理。

共享参数17,279,024，总参数18,927,302，共享比例91.2915%。三个任务共用完整前端与编码主干，仅末端轻量任务头不同；总量≤1B、共享>80%的模型约束满足，导出时继续强制核验。

原Transformer核心参数key/shape与原模型对应项一致，专项测试可显式载入这些核心张量。旧time/spectrum/gate等前端模块已经移除，因此旧完整权重不具有直接resume兼容性，核心输入分布也不再等同原主干。当前仍从零监督，未启动旧权重适配或声称预训练增益。

本轮只证明组件的可执行性、连接和接口合理性；准确率提升、抗过拟合、GPU速度/显存与国产化适配仍需后续实际验证。
