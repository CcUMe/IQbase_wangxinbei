## 明确结论与下一步优先级

| EMA方案 | 种子18 Acc | 种子19 Acc |
| --- | ---: | ---: |
| control | 66.9524% | 66.8710% |
| phase_shift_first14 | 67.5700% | 67.5221% |
| phase_shift_first14_phase_only | 67.6179% | 67.6802% |

1. **相位增强是本轮最有重复性证据的训练方向。** 相对同种子control，仅相位两次提高约0.666/0.809个百分点；组合提高0.618/0.651个百分点。主要收益不依赖加入循环时移，但不能证明时移在所有条件都无效。
2. **相位单项相对组合的微小领先尚未确认。** 两种子的差值为+0.048/+0.158个百分点；逐记录配对95%近似区间分别[-0.198,+0.294]和[-0.085,+0.401]个百分点，都包含零。不能称为已经获得稳定的新涨点。
3. **50%原始/50%相位增强不作为默认修复。** 主种子Acc67.278%，低于全量相位67.618%；虽然QAM合计Acc43.354%略高，但QAM全局Macro-F1更低，16QAM召回恢复伴随精确率/F1损失。只验证了这一比例/预算，不能外推所有混合策略都无效。
4. **QAM细分仍是下一阶段的独立目标。** source的五类QAM合计42.851%，仅相位两个种子均43.135%，没有显著跃升。整体增益不能解释成高阶QAM辨别已经解决。后续应同时要求QAM合计Top-1、Top-2和完整混淆下的F1改善，而非只提高某类召回。
5. **先稳定相位增强配方，再单独改共享时域I/Q前端。** 源模型已有幅度、相位差、局部/全局谱，因此不是再补同类输入；优先研究I/Q耦合与参数共享的局部提取，并保持原768×12 Transformer、三任务读出、损失和预算不变。保留原始观测、尺度与位置访问，避免为调制不变性牺牲参数估计。该结构方向尚未在本轮实现/验证，不能预告涨点。
6. **低成本备选是检查纯相位增强的类别覆盖。** 此前全类别负结果同时包含循环时移，不能代替“全调制类别只作相位旋转”的实验；扩大范围前须核对类别语义，并保留后9类与三任务保护条件。它是下一候选，不是已经证实的改进。

当前不优先扩参、增加第二套时频编码、继续堆分布统计、弱教师蒸馏或同时更改任务头。仓库另有Patch适配器/双视图一致性方案，其已有中途结果不能与本轮等同预算因素拆分混比，也不能据此宣布结构有效或无效。
