# C01 接收表征优化实验（2026-11-14）

本轮沿上一轮提出的“先检验接收与符号尺度建模，再扩参”的方向执行，已完成9组等预算单卡实验。没有找到明显改善；完整结果与配对比较统一写入 [汇总目录](../../artifacts/reception_exploration/summary_20261114)。正式配置与默认权重未替换。

## 问题与研究依据

此前通用正则、参数扩展、额外统计和循环相关探针都没有产生稳定的大幅提升。这次检验一个更具体的假设：短窗观测下的载频、时间尺度与接收表征，是否限制了原模型提取稳定调制信息。

- [RTN 原文](https://arxiv.org/abs/1605.00716)将可学习无线信号变换与分类联合训练；[AMR-STN](https://www.mdpi.com/2076-3417/9/5/1010)讨论接收参数误差及可学习补偿。本轮借鉴其问题设定，并非完整复现。
- [QAM 盲载频估计原文](https://perso.telecom-paristech.fr/ciblat/docs_recherche/articles/ieee_tw1.pdf)分析四阶非线性及其局限。本文最优估计器有特定模型与同步假设；本轮使用的是带可靠性筛选的四次方频谱工程近似，不称作论文最优算法。
- [2024 RF 同步研究](https://www.bgd.ed.tum.de/pdf/2024_RFSynchronization_ICMLCN_Petry.pdf)支持把同步视作独立建模问题；其任务与 C01 调制识别不同，不移用其精度。
- [MERLIN 作者论文](https://arxiv.org/html/2603.08174v1)研究低信噪比下的特征退化和同源高低质量配对蒸馏。这提醒我们区分“表征缺失”和“可观测结构被干扰”。本轮没有干净 C01 配对，不能宣称复现这类监督。

## 保留单一共享基座

使用历史约 96M 基座的固定副本：`artifacts/reception_exploration/20261114_104034_511636/source.pt`，来源为 `logs/finetune_v2/20261112_145913_822471/best.pt`。

原时域、频域、能量、绝对时间及三个任务头均保留。所有新增接收模块位于共享骨干内部，三任务都能读取。接收记忆版本约 95.898M 参数，输入投影版本约 95.717M；共享比例均约 98.06%。这满足本轮结构实验对单基座与共享比例的要求；新增非线性接收模块尚未接入原比赛导出接口。折叠后的原始输入控制恢复原结构，可使用现有导出器。

接收记忆分支使用六组以样点为单位的周期候选（2、4、8、16、32、64），RRC 匹配滤波假设、分数采样、局部接收特征与原始样点坐标对齐的交叉注意力。可学习版本增加受限的频率、相位、短均衡器、周期及定时修正。在原 Transformer 第一层之前残差注入；它没有增加第二套完整编码器。

输入投影分支更轻：只在原时域第一层卷积上增加一个零初始化输入投影，原始通路与新视图共同进入同一个主干。数学上等价于在输入通道维拼接两种视图后使用一个卷积，不是两个基座或预测集成。

## 等预算实验协议

所有 GPU 实验均在物理 GPU 0 单进程、串行运行。没有使用其他 GPU 进行训练或推理。

- 各组从同一固定权重开始，训练流、种子、batch 和步数相同；保存权重与训练流 SHA256。
- 每组 1200 次更新，batch 256，调制／协议／参数各 400 次更新。一个 batch 是同任务、同有效长度的独立记录；有放回抽样，1200 步不等于一次遍历全数据。
- 原权重学习率 `3e-5`，新增接收融合参数 `3e-4`，接收变换预测器 `3e-5`；AdamW、30 步 warmup、cosine 衰减至峰值的 20%，梯度裁剪 1，EMA 0.995。
- BF16 训练；FP32 输入和权重全量验证 118182 条，其中调制 20885 条。CUDA matmul TF32关闭，cuDNN TF32保持默认开启，各控制一致。验证按 512／1024 有效长度分别组 batch。
- 固定预算结束后同时保存 last 和 EMA，完整验证两者；中途小面板只作监控，不据此选 checkpoint。
- 对每种权重，与相同权重类型的普通续训控制作逐记录配对比较；载频输入另外与相同参数量的原始输入投影控制比较。
- 配对区间只反映当前验证记录的正确性差异，不代表不同训练随机种子的稳定性，也没有作多重比较校正。

实验包括普通续训、固定接收记忆、联合学习接收记忆、合成校准初始化、冻结校准预测器、原始输入投影、lag1 载频代理归一化输入、可靠性筛选四次方细化输入，以及接收分支按原 token RMS 换算的接入尺度实验。

## 已确认的机理现象

**合成校准能学到粗时间尺度，但没有证明真实 C01 同步成功。** 小预测器在独立合成记录上的周期相对误差中位数从约 87.25% 降到 10.00%；未用于训练的 256QAM 上从约 88.20% 降到 9.00%。数据使用明确已知的连续时钟、脉冲成形、频偏与噪声，不使用 C01 验证标签或参数。

**分类联合训练没有保留原校准能力。** 校准后接入 C01 联合训练，回到同一合成测试，周期相对误差中位数升到约 38.88%；冻结小预测器则逐张量保持一致，误差仍为约 10.00%。这里测的是合成域能力保持，不是 C01 的实际时钟误差，也不能直接解释全部分类错误。

**粗周期估计还远不足以保证整段符号对齐。** 若估计周期相对误差为 ε，经过 K 个符号后会积累约 Kε 个符号的时间漂移。9%–10% 的误差仍可能造成严重错位。因此当前候选滤波与重采样只能称接收假设，不能称已恢复真实星座。后续若做闭环定时跟踪，必须另行测精度与失锁率。

**新增接收分支在短程续训中参与很弱。** 冻结预测器版本在固定前14类128条监控记录上，分支残差／原 token RMS 的均值约 `0.000496`，即 0.0496%。关闭分支与正常开启的预测完全相同；临时放大10倍只改动2条预测，准确率未变、CE略升。该诊断不等同完整验证，也不支持将推理增益系数调大作为优化。

接入尺度实验仅将新残差按原 token 的有效位置 RMS 换算，尺度计算停止梯度，保留零初始化等价性。它用于区分“分支信息无用”与“接入尺度过弱”，不会强制替换原始观测。

**载频细化在可控数据有效，在 C01 是否有效需要独立评估。** 可复现第二组合成检查中，QPSK／16／64QAM 的频率误差 RMSE 从约 `0.003654` 降到 `0.002840` cycles/sample；256QAM 从 `0.004073` 降到 `0.003976`。后者仅约2.93%记录通过可靠性筛选；512条滤波复高斯空假设记录通过率为0%。这是有限合成控制，不能保证 C01 无误校正。

lag1 平均相位变化始终称“载频代理”；它并非真实 CFO。RRC、候选符号周期及合成噪声分布均不是已确认的 C01 生成条件。

**公开数据元信息未能补齐本地条件。** 下载了公开 EM-Bench 的300条调制记录，以全部2048个 float32 IQ 数值完全相等为准核查，没有匹配记录。没有把其 SNR／采样率迁移到 C01，也没有将这些公开记录加入训练。类名及量化网格相似不足以认定同一来源。

## 最终状态

9组训练全部完成，各1200步，每组last／EMA均完成全量三任务验证。没有达到预设的总体+1、前14类+2个百分点筛选门槛，因此停止继续叠加接收模块，未做独立训练种子确认，也不宣称当前最高值具有训练稳定性。

原始输入投影控制最高，EMA相对普通续训EMA约+0.139个百分点，当前验证记录配对区间约[+0.031,+0.246]个百分点；这个区间不衡量训练种子不确定性。它没有引入新信息，而且两套同输入线性卷积等价于相加权重。该结果更支持检查原时域前端优化速度，而非声称接收变换有收益。此前SAM候选约66.92%，本轮没有超过；不同预算与配方下的最高值不构成公平方法比较。

相对相同参数量原始输入投影控制，lag1／四次方输入的EMA调制准确率分别约-0.067／-0.105个百分点，前14类约-0.102／-0.157个百分点；对应配对区间均未提供正增益证据。不能把新增参数或前端学习率造成的小变化算成载频校正收益。

接入尺度换算后，固定128条监控记录上的接收分支／原token RMS从约0.0496%升至0.1857%，但EMA全量调制结果仍为66.689%。该改动确实增加了分支量级，没有产生分类收益；仍不等于接收假设已经估计准确或充分训练。

原始输入投影EMA候选已通过 [fold_raw_input_projection.py](../../code/training/fold_raw_input_projection.py) 折叠为原架构权重，见 `artifacts/reception_exploration/summary_20261114/raw_front_ema_folded.pt`。CPU三任务最大logit差约3.8e-6；全量GPU复验、真实导出和统一推理检查记录见汇总报告。它保留为小幅候选，不替换默认权重。

接下来有依据继续做的方向是：先建立足够精确、能保持的接收估计与闭环定时跟踪，再讨论符号表征融合；若要直接优化现有网络，先测原时域前端独立学习率，而不必继续加一个重复输入分支。MERLIN式同源质量配对与特征保留去噪可作为另一条路线，但需要明确数据条件或可控干扰配对，不能把不同记录的同类高RMS样本直接当同源干净教师。本轮未验证这些后续方法的C01收益。

这些结果限定在既有最好权重上的短程续训；不证明接收建模、充分从头训练或其他方法均无效，也没有证据宣布C01的可达上限为66%–67%。正式配置、默认权重、原始数据与历史训练日志均保留。
