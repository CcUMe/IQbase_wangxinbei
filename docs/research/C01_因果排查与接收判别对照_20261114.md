# C01原因排查：评估失配、接收表征与质量混合监督

本轮得到了新的确定发现：IQFormer存在可修复的训练／评估归一化失配；同一约96M骨干在可控数据上的接收处理和损失分配也产生了显著差异。**主模型的真实C01成绩尚未因此提高，不能宣称全部根因已经解决。**

结果目录：`artifacts/causal_diagnosis_20261114/summary`。所有GPU实验均物理GPU0单进程串行；其余GPU未用于本轮工作。原数据、划分、标签、正式配置和默认权重保留。

## 1. IQFormer低分有明确的评估原因

检查的是已有RMS运行`logs/compare_iqformer/20261113_212535_300325`。已完成32轮，训练数据每轮完整遍历；历史best是第27轮，last是第32轮。它不是此前未归一化的raw运行。

所有对照冻结同一来源权重，不更新卷积、LSTM、注意力、分类头以及BN的gamma/beta。完整验证20885条调制记录。

| 处理 | best Acc | best Macro-F1 | last Acc | last Macro-F1 |
| --- | ---: | ---: | ---: | ---: |
| 原始eval | 46.378% | 45.993% | 42.432% | 39.789% |
| 仅输入BN用批统计 | 47.264% | 46.941% | 42.758% | 40.287% |
| 全部BN用批统计，仅作诊断 | 62.504% | 62.194% | 62.571% | 62.281% |
| 分层校准全局统计，训练数据 | 43.615% | 37.870% | 43.840% | 37.956% |
| 分层校准512／1024各自统计，训练数据 | **63.179%** | **63.022%** | **63.309%** | **63.140%** |

**原因支持链：**

1. 输入按512／1024原生长度分桶，调制数据中这两种长度分别对应不同信号群体。训练时每个batch的BN使用该群体的统计，统一running statistics却混合不同群体。
2. 只修改输入BN改善很小；全部BN改用批统计会恢复约16—20个百分点。验证batch按不依赖标签的规则打乱，换一套batch组成仍约62%—63%，没有依赖按类别排列的验证batch。
3. 普通一次全网BN重校准也没有恢复；精确全局分层校准仍约43%。问题不只是运行均值估计不够准确，统一归一化条件本身也不匹配。
4. 仅使用4096条训练IQ，按网络执行顺序逐层测量总体矩，祖先层始终使用已校准的eval统计。分别为512／1024保存统计后，恢复到63.18%／63.31%。校准中不使用类别标签或验证记录。
5. 校准后只根据输入有效长度选固定统计；单条与batch预测、512→1024→512切换均通过。CPU最大logit差约3.8e-6，长度切换前后差为0；逐张量验证所有学习参数未变化。

该思路与[Domain-Specific Batch Normalization](https://openaccess.thecvf.com/content_CVPR_2019/html/Chang_Domain-Specific_Batch_Normalization_for_Unsupervised_Domain_Adaptation_CVPR_2019_paper.html)及[Rethinking Batch in BatchNorm](https://arxiv.org/abs/2105.07576)讨论的归一化条件问题相关。本轮是冻结权重、按可观测长度校准统计的诊断适配，不是完整复现论文训练算法。

混合分布的均值、方差即使估计精确，也包含群体间差异，不能替代每个群体训练时使用的归一化。因此混合总体统计恢复不了两种群体，而条件统计可以同时恢复。

末轮前14类从40.071%到46.737%，后9类从46.123%到89.202%。在另一组与校准样本完全不重叠的4096条训练记录上，末轮原eval为42.725%，条件统计为64.233%，接近验证63.309%。**此前IQFormer的训练／验证表现不应直接解释成“模型学不动”或数据上限。** 受失配指标驱动的最佳轮次、早停和plateau调度也需要重新审视；本轮未重跑整段训练来量化其影响。

## 2. 该BN问题不解释主模型的66%—67%平台

实际检查历史95.7M主模型：**0个BatchNorm、25个LayerNorm**。不能把IQFormer这次约20个百分点的恢复套用到主模型。

真实C01的同一20885条验证记录上，折叠候选主模型66.842%，修正统计的IQFormer63.309%。前14类12735条中：

| 正确性关系 | 条数 |
| --- | ---: |
| 两者都正确 | 5027 |
| 只有主模型正确 | 1496 |
| 只有IQFormer正确 | 925 |
| 两者都错误 | 5287 |

这是错误互补的描述，不能把联合正确率当成可达上限或竞赛集成方案。共同错误也不能证明这些样本没有信息。它说明先前“已有方法都差不多”的比较依据需要纠正，现有主模型也没有覆盖所有其他模型的判别行为。

## 3. 接收处理确实能影响同一骨干的学习

构造独立合成机制实验：BPSK、QPSK、8PSK、16／64／256QAM，共6类。脉冲为已知RRC，8样点／符号，随机频偏、相位、增益和定时偏移，独立复高斯噪声。输入长度1024，训练15360条，独立测试7680条，名义波形SNR为-10／0／10／20／30dB，各类与条件平衡。

这是受控AWGN／固定脉冲设置，**不是C01生成条件或真实SNR的估计**。与上轮连续未知周期的校准数据也不同。

使用原历史骨干配置，约95.7M、仅调制输出改为6类。随机初始化，不加载预训练或C01学习权重。每组1800步、batch128、相同初始张量和训练流、AdamW3e-4、warmup＋cosine、裁剪5，固定末步测试，不按测试集挑权重。

- 原始视图：同一条受扰IQ观测。
- 已知接收条件视图：使用生成器真实的频偏、相位、增益、周期和定时，匹配滤波后保留112个符号样本，再重复为896点。接收处理不读取类别或发送符号值；真实发送符号只用于EVM检查。
- 两种视图来自同一记录，但这项对照联合改变多个接收因素，不单独归因于载频或时钟。

| 测试条件 | 原始IQ→同骨干 | 已知接收视图→同骨干 |
| --- | ---: | ---: |
| -10dB | 14.974% | 37.826% |
| 0dB | 40.365% | 66.536% |
| 10dB | 61.654% | 84.245% |
| 20dB | 71.875% | 86.328% |
| 30dB | 72.982% | 86.784% |
| 全部条件 | 52.370% | 72.344% |

给出已知接收表征带来约20个百分点总体差异。这排除了“这个骨干对所有输入条件都只能在相同高度”的说法，但没有证明C01也能获得同样增益。

## 4. 粗周期估计不能当作符号同步已经完成

对同一受扰记录，其他接收条件保持正确，比较正确采样周期与+10%错误周期。使用同一个已知星座／噪声模型似然判别器。它是乐观的已知模型参考，不是信息论上界，也不是C01可部署分类器。

额外补做了**每条都只取100个有效样本**的对照，排除错误周期导致有效样本变少这一干扰。重放生成的原始观测和接收视图已与原实验逐值核对一致。

| 名义SNR | 正确周期，100样本 | 周期+10%，100样本 |
| --- | ---: | ---: |
| 10dB | 99.935% | 16.667% |
| 20dB | 100.000% | 16.667% |
| 30dB | 100.000% | 16.667% |

结果验证了该接收判别链对周期误差的敏感性。前轮约9%—10%的周期误差仍是粗估计，不能据此宣布星座已恢复。该结果不表示错误周期视图对任何其他分类器都不可辨识，也不表示C01具有同样误差。

## 5. 细粒度学习还受混合质量监督影响

已知接收视图的同骨干在20／30dB仍只有约86%。再做一个控制：**完全保持初始化、所有batch、随机种子、高质量记录曝光量和这些记录的损失系数相同，只屏蔽低于20dB样本的损失。**

原损失为`sum(CE_i)/B`；控制损失为`sum(1[SNR_i>=20]*CE_i)/B`。SNR只用于合成诊断中的损失选择，不进入模型，也不用于C01训练。

| 测试条件 | 全条件混合监督 | 仅高条件损失 |
| --- | ---: | ---: |
| 20dB | 86.328% | 97.135% |
| 30dB | 86.784% | 98.503% |
| 30dB的256QAM Recall | 28.125% | 94.531% |
| 全部条件 | 72.344% | 60.664% |

高条件共3072条，准确率从86.556%到97.819%，逐记录配对提升约11.263个百分点，条件于这两个模型的95%区间约[9.992,12.535]个百分点。未重复训练种子，不把区间解释为训练稳定性。

这说明在已知条件下，现有骨干可以学好更精细的调制区分，而质量混合的学习安排确实影响结果。**本实验没有把梯度方向冲突、Adam状态和剪裁等进一步分离，不能直接宣布其中某一个是根因。**

总体结果下降说明不能把“屏蔽困难样本”当优化方案。真实C01也没有这些SNR标注，更不能把低RMS等同低SNR后照搬。后续应研究保留困难条件覆盖的阶段训练、可靠性与损失分配，并完整验证全部条件和三个任务。

## 6. RMS归一化后仍可保留精细类别几何

从同一已知接收视图提取112个符号，按每条RMS归一化，与重复符号输入骨干时的归一化一致。使用固定32×32二维软直方图、训练侧标准化和线性逻辑回归。分类器不读取星座模板、真实SNR、噪声方差或发送符号值。

| 条件 | 已知接收视图→同骨干 | 归一化直方图→线性头 |
| --- | ---: | ---: |
| 10dB | 84.245% | 96.224% |
| 20dB | 86.328% | 99.219% |
| 30dB | 86.784% | 99.023% |
| 全部条件 | 72.344% | 78.164% |

该小读出有约6150个分类系数，固定配方训练，收敛检查通过；没有按测试结果调参。这支持在可控域检查细粒度几何表征与学习策略，而不是继续堆参数。它依赖已知接收视图，不能直接当成C01原始IQ的99%结果。

## 7. 当前结论与下一步

可以确定：IQFormer此前很低的验证值包含明显的归一化条件失配；原始输入／已知接收输入、粗时钟／正确时钟以及混合质量监督／选择性监督在可控实验中都有实质区别。现在有证据支持把后续工作集中到可靠接收、符号幅相几何及不同质量条件的学习分配。

仍未确定：真实C01各类受何种接收条件主导、这些机制各解释多少错误，以及如何在单一共享三任务基座中实现稳定净增益。主模型没有此次BN问题，本轮没有提升其约66.8%的真实C01成绩。不能宣布数据上限，也不宣称已找到全部原因。

应先把IQFormer的训练与评估归一化条件统一，再评价其结构能力；不能沿用失配验证结果选择最佳轮次和调度后，直接认为其已充分收敛。主模型下一轮应优先验证细粒度幅相几何的保留与可靠性、条件学习分配，保留原始观测及三任务信息通路，再考虑扩参。
