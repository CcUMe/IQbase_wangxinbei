这次确实加载了 QK 归一化、非活动任务头保护及 1e-4 学习率。训练从零初始化，未加载结构预训练基座。第 44 轮完整验证有 118,182 条记录，调制准确率 64.2279%，协议准确率 94.4180%，参数代理精度 0.731866，总代理分 76.8684。裁剪前梯度 P95 为 1.1378，原先的注意力尺度失控已经不是当前训练的主要证据。

第 8 到 44 轮，调制训练交叉熵从 0.716 降到 0.00845，完整验证准确率仅从 63.706% 到 64.228%。独立固定抽样的 2,944 条训练信号全部分类正确，2,944 条验证信号准确率为 64.91%、交叉熵 3.56、平均预测置信度 93.26%。这表明明显的过拟合与过度自信，不能继续把训练损失下降当成泛化提升。

## 相位敏感性与因果边界

对相同波形施加整窗 90° 复数相位旋转，保持幅度、功率谱、时间位置和相对相位，训练调制准确率由 100% 降到 72.49%，验证由 64.91% 降到 53.02%。这确认了相位敏感性，但不能单独证明它造成了原始分布下的全部泛化误差。

新增训练增强仅改变整窗初始相位。它不引入频移、不移动时间、不做共轭，不修改原始缓存或标签。验证和推理不增强；结构预训练的离散目标不能直接沿用旋转前标签，因此当前也不对它增强。旧配置缺省关闭。

## 对照实验记录

四组均由本次第 44 轮同一检查点开始，各 2,400 次更新、每批 256 条、采样 seed=2027，并重置优化器。每 800 次更新评估固定 8,064 条验证记录。

1. `control`：学习率 4e-5，保持无增强、无标签平滑。
2. `phase`：与 control 相同，仅相位旋转概率改为 1。
3. `smoothing`：学习率 1e-4、标签平滑 0.05、无相位增强。
4. `smoothing_phase`：与 smoothing 相同，仅相位旋转概率改为 0.25。

前两组能比较全量相位增强，后两组能比较温和相位增强。第二对同时改变学习率和平滑，不能将其相对第一对的差异完全归因于标签平滑。它们是已过拟合权重的短程热启动实验，不能替代从零开始的配方验证。

各目录的 `resolved_config.json`、`history.json` 和 `validation_rows.json` 保存实际设置、全过程和验证行号。最终汇总见 [summary.json](../artifacts/generalization_20261111/summary.json)。

首四组固定子集的起点为 77.1452 分、调制 63.7568%。2,400 次更新后，control / phase / smoothing / smoothing_phase 分别为 76.8733 / 76.6002 / 76.6960 / 76.7134 分，调制分别为 63.1114% / 62.7038% / 63.5190% / 63.3832%。这些结果不支持把候选配方直接启用。

标签平滑候选又在全部 118,182 条记录上验证：调制 64.3476%、代理分 76.6463，调制交叉熵 1.5067。准确率相比原 64.2279% 仅高 0.12 个百分点，未进行多种子重复，不视为明确收益；置信度改善不能当成判别能力已提升。

根据用户明确的调制优先目标，追加两组小模型对照，均从原 17M 的第 5 轮权重开始、LR=3e-4、非活动头保护开启、相同采样 seed=2027，训练 4,800 次更新并按调制准确率选检查点。对照不增强，实验仅对纯调制记录做随机相位旋转和循环平移，两者概率均为 1。参数、协议和多标签配对记录不移动。全部验证记录上的调制准确率分别为 63.3852% 和 62.2169%，专用增强没有优于匹配对照，也保持关闭。此结果只涉及这些热启动设置，不能用来证明增强或结构预训练普遍无效。

修整后的 95M 在固定 16 条/任务/长度诊断中，1024 点调制信号末层 Q/K RMS 为 1，注意力分数最大绝对值约 7.75，归一化熵约 0.69，近单点注意力比例为 0。时间分支/全局频谱 RMS 约 2.43/2.71，归一化后时序变化比例约 0.63。未看到先前的幅度爆炸或明显时序塌缩；这一小批次检查不等同于全分布证明。对应训练调制梯度已很小，参数任务仍产生梯度，但任务梯度的余弦矩阵没有提供强烈冲突证据，不能直接将误差归因于负迁移。见 [特征及梯度诊断](../artifacts/generalization_20261111/large_feature_diagnosis.json)。

## 扩参的结论与当前交付

用户仍计划扩参，小模型仅作快速定位。已观察到大模型能更充分拟合训练集，但新增容量没有转化为相应的验证收益；当前证据支持过拟合与无效的训练后期更新，不支持“数值正常即扩参成功”。当前运行是从零监督学习，尚无完整结构预训练和同预算缩放对照，不能把基座表征学习路线写成已经验证。

下一步需要区分共享表征不足与读出头过拟合，例如冻结基座的正则化读出对照，以及具有明确下游对照的结构预训练；再比较相同数据覆盖、相同有效 batch、多个规模和各自调优后的学习率。多任务冲突、输入 token 粒度、结构目标是否有益仍属于待检验因素。当前未解决调制准确率瓶颈，不要求用户再次跑相同 80 轮验证这个结论。

默认 `weights/` 已更新为本次真实训练的 95M 第 44 轮模型。原 17M 默认导出备份于 `artifacts/generalization_20261111/previous_default_weights/`，本次导出副本位于 `current_weights/`。导出张量逐项核验和官方 6 条样例 CPU 推理及输出校验均通过。它修正的是推理使用旧权重的问题，不宣称这修复了调制泛化。

主配置保持 95M 及现有优化配方，新增增强项均显式为 0。共 22 项回归检查通过，训练入口的双进程 CPU 增强检查通过。本轮训练实验只使用 GPU 2、3，至多同时运行两组训练；最初的只读诊断使用 GPU 0，其余 GPU 诊断使用 2。全部实验已结束。结果不代表隐藏测试成绩。
