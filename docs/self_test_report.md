## 通信兼容处理

按用户确认，本机仅支持 0、1 / 2、3 / 4、5 的双卡组。代码拒绝跨组两卡和超过两卡的本机训练。

当前环境即使使用有效卡组，默认 NCCL 主机 cuMem 分配路径也会触发底层崩溃。最小通信程序确认，单独设置 `NCCL_CUMEM_HOST_ENABLE=0` 后 all-reduce、DDP 初始化和反向传播通过；完整双卡训练随后通过。因此代码只在双卡训练进程中默认设置该兼容值，保留 GPU P2P。未更改系统或驱动配置。NVIDIA 对 cuMem 主机内存问题及回退有对应[运行时说明](https://docs.nvidia.com/deeplearning/nccl/user-guide/docs/troubleshooting/runtime_and_mpi_issues.html)。
