# 统一基座的信息保留与模块分工优化

2026-11-12，Asia/Shanghai。当前入口仍为code/configs/supervised/main.json5，单前端、单共享基座、从零监督。此次不再增加全局编码器或新损失，针对前向信息保留、上下文分工和读出捷径作结构约束。

## 当前结构

共享I/Q与局部谱前端 → 128点局部BiLSTM → 局部卷积/16-token窗口注意力阶段 → token投影 → 原8层Transformer核心 → 深层主导调制读出／协议读出／信号值感知七参数读出。

主干阶段宽度64/128/192、深度1/2/2及Transformer 384×8保持；1024点三份跨层特征仍为64×384、256×192、1024×64。窗口内BiLSTM双向，窗口之间不传隐藏状态；相邻阶段块的窗口注意力采用半窗偏移和零padding，不循环连接首尾。

## 1. 局部幅相值可读，不完全依赖归一化后的隐向量

从同一次RMS归一化后的I/Q确定性地提取六个值：I、Q、log(1+功率)、相邻log功率变化、可靠性加权的相邻相位差实部/虚部。第一对相位差为0，无效位置为0；不推断真实SNR、符号周期或采样率。

六个值没有逐token LayerNorm，归一化I/Q在前两个通道逐点保留。每个阶段将对应样点块折叠后做一个小线性投影，回注到残差路径；折叠投影不宣称理论无损。完整高分辨率六值同时保留到任务读出，防止只能从深层隐向量恢复幅相信息。

时域投影、融合后、BiLSTM后以及阶段输出不再统一做后置LayerNorm。融合与循环更新改用归一化的更新支路和小残差增益，保留身份路径；Transformer与各更新支路内部的PreNorm继续保留。

原始整段log RMS保留给参数头，不再直接广播到早期分类特征。帧级RMS归一化仍存在，其作用与逐token归一化不同。

## 2. 前半段局部，后半段全局

旧阶段中的全局加性注意力在当前机制模式下替换为局部窗口注意力；BiLSTM由完整记录递归改为局部128点窗口递归。保留相邻时刻顺序、局部卷积和窗口偏移，长程关系主要交给深层Transformer。

窗口128与16是工程超参数，不代表真实符号周期。卷积和重叠谱窗仍能跨窗口边界传递局部信息，深层Transformer再整合全局关系。模块级远端窗口干预误差为0，不意味着整个前端在任意128点边界上完全独立。

全局频谱仍只计算一次，但其描述不再广播到BiLSTM/阶段编码的输入；保存后只用于跨层读出。计算可以发生在前端，影响发生在读出端。完整模型梯度干预确认早期阶段特征不依赖全局谱分支参数。

## 3. 调制头以深层表征为主

原三份特征拼接分类改为：

`z = 深层描述 + alpha * tanh(细节修正)`，`alpha = max_ratio * sigmoid(a)`。

深层描述只从Transformer输出计算：注意力均值、标准差与普通均值，投影到256维。局部修正读取中/细层描述和按细层注意力汇总的六值均值/标准差。之后只有一个256→256→23分类器。

alpha初始0.1，最大0.25；上限约束每维特征修正幅度，不约束最终logit、概率或梯度贡献比例，也不保证分类器绝不依赖局部信息。干预浅层融合摘要不改变调制主描述；局部修正可以改变，但幅度受限。

## 4. 参数头直接读取信号值

七个查询用同一套注意力权重读取语义memory和独立六值memory。语义key/value可以归一化，六值不经过语义LayerNorm，而是直接加权汇总。三个尺度的六值memory按其样点块均值对齐，高分辨率部分仍保留完整逐点六值。

每字段输入为语义局部192＋全局192＋信号值6，共390维，接独立390→128→1 MLP及已有网格头。协议头保持原有轻量摘要读出。七字段、原单位逆变换和有效标签mask契约不变。

专项测试固定语义memory后将六值放大3倍，信号值读出也放大3倍、语义输出不变，证明该值通路没有被语义归一化消除。这不等于最终参数预测必须与输入幅度线性变化，字段MLP仍按监督目标学习。

## 配置

所有新增控制集中在model.hierarchy.mechanism，无新增实验配置：

| 字段 | 默认 | 含义 |
|---|---:|---|
| enabled | true | 启用本次信息保留、局部建模及读出约束 |
| recurrent_window | 128 | 原样点局部递归窗，须整除512 |
| attention_window | 16 | 每阶段的局部token窗 |
| signal_gain | 0.1 | 各阶段信号值回注初始增益 |
| detail_max_ratio | 0.25 | 局部修正逐维幅度上限 |
| detail_initial_ratio | 0.1 | 局部修正初始尺度 |

优化器、任务采样与监督损失保持当前配方：AdamW 3e-4、500步warmup、cosine最低比例0.05、40epoch上限、8次完整验证早停；CE、有效字段MSE和原网格辅助损失。未启用FR、SupCon、PCGrad或新预训练目标。旧机制模式的完整pt不能直接resume到当前模式。

## 尚不能证明的结论

以上证明结构约束生效，不证明准确率或抗过拟合收益。信号值能被读取不等于模型一定正确使用；局部窗口可能限制某些中程关系；下采样不宣称无损或完全抗混叠；有界修正不等于贡献比例上限；多任务梯度冲突也未被消除或在当前训练后实测。

这些工作针对前向信息保留与模块分工。GPU显存/吞吐、正式验证指标、国产平台部署和旧权重迁移仍需后续检验。
