# 实现说明

## 数据边界

`prepare_data.py` 使用全量审计得到的波形内容哈希，按确定性 64 位哈希阈值划分；同一组不会跨训练/验证。它是近似 90/10 的组级随机划分，不执行精确配额优化。小数据限额按分类类别/参数长度轮转选取，再恢复重复组完整性。六个样例及其内容组从两侧隔离。

训练侧拟合七项中心与标准差、通信及计数取值表。只有通信三项与脉冲数可以启用网格头，脉宽、PRI、时延即使在很小子集中也保持连续回归。`--merge-paired` 只在训练侧合并相同波形的真实标签并集；验证保持原始记录和有效位。

当前精确哈希分组不等于设备、会话或干净父波形隔离。缺少相关元数据时，不能将本地验证结果称为真实跨设备评测。

## 共享网络

`RFModel` 的 `backbone` 被全部任务共享：

- 时域输入包括共用 RMS 归一化的 I/Q、包络，以及可选的可靠性加权相邻差分相位实虚部。
- 局部时频谱由实数固定 DFT 卷积产生，窗中心与时间 Patch 中心相同；保留双边谱。全窗功率谱提供更细的频率位置参考。
- 门控融合后加入可见能量与绝对样点坐标特征，避免全局池化抹去时延起点。共享 Transformer 使用 RoPE。
- 分类头采用有效位感知池化；七个轻量查询从局部 Token 汇总参数相关特征，再与全局特征共同回归。
- `grid_residual` 对训练侧已见的通信/计数取值计算概率期望，并增加有界小残差；连续模式作为对照。

固定 DFT 核不是可训练参数。共享比例按去重的可训练权重统计，分母包含全部最终输出头；预训练辅助头单列并在导出时移除。每个训练实验和导出都会实际检查共享比例 >80%、最终参数不超过 1B。

## 预训练与结构词表

学生端先在原始 I/Q 上遮挡，再计算归一化、包络、相位、时频特征。RMS 仅由可见点计算。完整波形只用于连续目标和离线教师目标。回归检查会改变遮挡真值并确认两条输入流及学生输出不变。

第一轮词表对原始归一化 Patch 向量做单位范数聚类；第二轮使用冻结编码器特征。实际采用平衡抽样和球面聚类，是本项目的可执行实现。BPE 在有限训练序列上拟合，限制每个符号最长展开 5 个原子位置，按合并秩执行并回填标签。教师、特征定义、合并规则与数据划分指纹均绑定到词表版本。

验证侧可以用固定教师和固定词表生成目标以监测预训练损失，但从不参与聚类或合并拟合。预训练验证损失只能诊断收敛；是否采用该方案仍需下游三任务的同划分比较。

## 训练、恢复与输出

训练启动后由 rank 0 在 --output 父目录下创建上海时区时间戳子目录，并将同一路径广播给其他 rank。检查点、配置及日志均写入该运行目录，run_info.json 记录创建时间及续训记录，父目录 latest_run.json 通过原子替换记录最近创建的运行。断点续训固定使用检查点所在目录，可省略 --output；init-checkpoint 则创建新运行。完整流程测试脚本会解析实际路径后传给后续阶段。

训练采用任务均衡、有放回、按长度组批，DDP 不同 rank 使用同任务/长度安排和不同样本抽取。所有头都保留零梯度连接，避免多任务交替批次导致未完成的分布式梯度同步。

检查点保存模型、优化器、调度器、混合精度状态、epoch、批次位置、总步数、数据指纹、训练配置和词表签名。断点恢复使用确定性采样/遮挡/Dropout 步数种子。更换词表属于新一轮训练，使用 `--init-checkpoint` 只加载共享基座，重新初始化任务/结构预测头。

配置已采用分组版本 2，详细字段见 [配置说明](../code/configs/README.md)。训练支持梯度累积和 DDP no_sync，scheduler 按优化器更新而非微批次推进，cosine 的预热与下限均显式可配。旧版调度的预热截断和固定下限不再使用，旧格式 checkpoint 不直接跨版 resume。

推理完全依赖导出的单模型和配置，不读取数据真值或有效位。文件按批读取，批内按长度分桶，随后还原原始顺序。非有限值或非法结构会报错，避免静默输出占位答案。
